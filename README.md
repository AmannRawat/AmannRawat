An AI-powered platform designed to help developers prepare for technical and behavioral interviews.

### 🕸️ [SiteMind AI — RAG-Based Website Support Agent](https://github.com/AmannRawat/SiteMind-AI)

A website support agent that crawls website content, indexes it, and answers questions using retrieved context.

**Key engineering work**
- Built a website ingestion pipeline using Puppeteer, chunking, Gemini embeddings, and Qdrant.
- Implemented asynchronous crawling and indexing with BullMQ and Valkey.
- Added job progress tracking, retry handling, resumable checkpoints, and incremental re-indexing.
- Wrote backend tests covering API behavior, crawling, job processing, embeddings, and vector storage.

**Testing:** 41 backend tests passing in the reported test run.

**Tech:** React • Node.js • Express • Puppeteer • Gemini • Qdrant • BullMQ • Valkey • Docker
